MOTION

(01) What it does

Ask Claude for a one-page site and get a single HTML file in a bold, typography-first style: a giant wordmark, flat colour and motion that does the job ornament would do.

The skill fixes the parts that make a page feel designed: three typefaces with clear roles, thin rules instead of boxes, and restrained animation that never animates layout.

It also handles the parts people forget: a reduced-motion path, mobile sizing that keeps the crop, and copy that is real rather than lorem ipsum.

  • 01 Typographythree voices Heavy grotesque, italic serif, monospace. Each has one job. →

  • 04 Motiontransform only Letters rise from a mask. Rules grow. Layers scrub at different speeds. →
