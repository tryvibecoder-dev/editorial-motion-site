# Направления 151–200

Формат записи: суть, типографика, цвет, форма и сетка, где работает, чего избегать.

### 151. Карточный интерфейс
- **Суть:** Один объект на экран, свайп влево или вправо. Решение принимает пользователь.
- **Типографика:** крупный заголовок карточки, мелкое описание.
- **Цвет:** нейтральный фон, карточка светлее.
- **Форма:** прямоугольник, скругления, тень.
- **Где:** подбор, знакомства, онбординг, выбор товара.
- **Избегать:** карточек без понятного действия.

### 152. Лента
- **Суть:** Бесконечный поток публикаций. Важны ритм, плотность, понятный порядок.
- **Типографика:** имя автора, дата, текст в одну-две строки.
- **Цвет:** белый или тёмный фон, один акцент для действия.
- **Форма:** блоки на всю ширину, разделители.
- **Где:** соцсети, новости, медиаплатформы.
- **Избегать:** одинаковых блоков без иерархии.

### 153. Чат
- **Суть:** Сообщения в хронологии, пузыри, поле ввода внизу.
- **Типографика:** гротеск среднего размера, время мелко.
- **Цвет:** два цвета для сторон разговора.
- **Форма:** пузыри с хвостиком или без, отступы.
- **Где:** мессенджеры, поддержка, ассистенты.
- **Избегать:** длинных сообщений без разбивки.

### 154. Редактор кода
- **Суть:** Панели, вкладки, дерево файлов, терминал внизу. Плотность для работы часами.
- **Типографика:** моноширинный, 13–14 пикселей, подсветка синтаксиса.
- **Цвет:** тёмный фон, тонкие разделители, один акцент.
- **Форма:** прямые углы, узкие полосы.
- **Где:** разработка, инструменты кода.
- **Избегать:** декоративных скруглений и больших отступов.

### 155. Таблица
- **Суть:** Строки и колонки, закреплённая шапка, фильтры. Данные важнее всего.
- **Типографика:** гротеск, моноширинные цифры.
- **Цвет:** белый, серый для чередования строк, один выделенный.
- **Форма:** сетка, тонкие линии, ячейки.
- **Где:** таблицы, аналитика, учёт.
- **Избегать:** карточек вместо строк.

### 156. Канбан
- **Суть:** Колонки статусов с карточками задач. Видно, что где находится.
- **Типографика:** гротеск, заголовки колонок, числа в счётчиках.
- **Цвет:** нейтральные колонки, цвет для приоритета.
- **Форма:** вертикальные колонки, карточки с тенью.
- **Где:** управление задачами, команды.
- **Избегать:** слишком большого числа колонок.

### 157. Таймлайн

- **Типографика:** даты крупно, описание мелко.
- **Цвет:** одна линия, точки статусов.
- **Форма:** линия, точки, блоки по сторонам.
- **Где:** истории компаний, проекты, биографии.
- **Избегать:** неравномерного масштаба дат без пометки.
