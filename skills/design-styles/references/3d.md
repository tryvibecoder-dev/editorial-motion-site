# Как делать 3D-объекты

Этот файл описывает процесс: от идеи до объекта, который работает в браузере и не тормозит. Выбор инструмента зависит от задачи: для статичной картинки подходит одно, для интерактивного сайта другое.

## 1. Сначала решить, зачем 3D

3D оправдан, когда объект нужно повернуть, рассмотреть с разных сторон, показать глубину или когда плоская картинка не передаёт форму. Если задача только выделить кнопку или украсить заголовок, 3D обычно лишний. Проверка: если бы объект был плоским, пользователь понял бы то же самое? Если да, 3D не нужен.

## 2. Выбрать тип модели

- **Низкополигональная** (примерно 500–5000 полигонов). Грани видны, плоское освещение. Легко грузится, подходит для иконок, игрушек, фоновых сцен.
- **Средняя** (5000–50000). Гладкие поверхности с запечёнными текстурами. Для продуктов и предметов на сайте.
- **Высокая** (от 50000). Для рендера, выставок, фото. В браузере почти не используется без оптимизации.

## 3. Инструменты

- **Blender** (бесплатный). Полный цикл: моделирование, материалы, свет, рендер, экспорт в glTF. Лучший выбор для большинства задач.
- **Spline** (браузерный). Быстрые интерактивные сцены и анимации, экспорт в веб. Хорош, чтобы начать без установки.
- **Cinema 4D** (платный). Motion-дизайн, анимация текста и объектов.
- **SketchUp**. Архитектура и интерьеры, простое моделирование.
- **Three.js или Babylon.js**. Код для показа объекта в браузере, если нужна своя логика.

Для веба почти всегда используют формат **glTF (.glb)**. Он компактный и понятный браузерам.

## 4. Порядок работы в Blender

1. **Блокинг.** Грубые формы простыми примитивами: куб, цилиндр, сфера. Масштаб и пропорции важнее деталей. Ставь объект в метрах, чтобы размеры совпадали с реальными.
2. **Моделирование.** Режим Edit, экструдирование, масштаб граней. Следи за числом полигонов: в Statistics видно количество.
3. **Развёртка UV.** Разложи поверхность на плоскость, чтобы на неё легла текстура. Швы ставь там, где их не видно.
4. **Материалы.** Для веба достаточно трёх-четырёх каналов: базовый цвет, шероховатость (roughness), металличность (metallic), нормаль. Для стилизованных объектов хватит плоского цвета.
5. **Свет.** Один ключевой источник, один заполняющий слабее, фон. Тени мягкие, если нужен спокойный вид. Для стилизованного 3D свет часто плоский, намеренно.
6. **Камера.** Фокусное расстояние 35–85 мм, как у портретного объектива. Широкий угол искажает форму.
7. **Экспорт.** File → Export → glTF 2.0, формат .glb, включить «Apply Modifiers», выключить камеру и свет, если они не нужны в браузере.

## 5. Оптимизация для сайта

- Целевой вес модели: до 1–2 МБ для одного объекта, до 5 МБ для сцены.
- Текстуры до 1024 или 2048 пикселей. Большие текстуры съедают память телефона.
- Сжатие: Draco для геометрии, KTX2 или WebP для текстур. Инструмент gltf-transform поможет сжать файл.
- Удали скрытые полигоны, дубли вершин и лишние материалы.
- Ограничь пиксельное соотношение: `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`.

## 6. Показ в браузере

Для простой страницы хватит `<model-viewer>` от Google (подключается одной строкой через CDN, поддерживает вращение, масштаб и AR на телефоне). Для своей логики используй Three.js:

- сцена, камера, рендерер;
- загрузка модели через GLTFLoader;
- OrbitControls для вращения мышью и пальцем;
- цикл отрисовки через `requestAnimationFrame`.

Если пользователь не взаимодействует, останавливай рендер или снижай частоту кадров: это экономит батарею.

## 7. Стили 3D, которые легко сделать сами

- **Низкополигональный.** Меньше полигонов, плоские грани, без сглаживания, два-три цвета.
- **Пластиковая игрушка.** Гладкие формы, высокая металличность у бликов, яркие материалы.
- **Глина (claymorphism).** Матовый материал, мягкий рассеянный свет, скругления.
- **Стекло и хром.** Прозрачность, отражения через окружение (environment map), высокая металличность.
- **Изометрия.** Ортографическая камера под 30–35 градусов, без перспективы.

## 8. Частые ошибки

- Полигонов больше, чем нужно: модель тормозит на телефоне.
- Слишком тёмная или пересвеченная сцена без нормального освещения.
- Текстура 8k там, где объект на экране 200 пикселей.
- Перспективная камера там, где нужна изометрия, или наоборот.
- Отсутствие запасного варианта: если WebGL не поддерживается, покажи картинку.

## 9. Доступность

- Всегда давай текстовое описание объекта для программ чтения с экрана.
- Не делай вращение обязательным для понимания. Важные сведения должны быть в тексте.
- Не включай автоматическое вращение, если пользователь уже взаимодействует с объектом.
- Отключай анимацию для `prefers-reduced-motion`.

## 10. Чек-лист перед публикацией

- [ ] Вес модели в пределах бюджета.
- [ ] Модель открыта на телефоне и на слабом ноутбуке.
- [ ] Есть запасная картинка.
- [ ] Масштаб в реальных единицах.
- [ ] Текстовое описание для незрячих.
- [ ] Отключена анимация при reduced motion.
