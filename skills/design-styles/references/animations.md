# 40 видов анимации

Для каждого вида: что делает, когда уместно, длительность и кривая движения. Длительности ориентировочные, их нужно проверять на реальном устройстве.

Общие правила:
- Анимация должна что-то объяснять: появление, переход, состояние, связь между элементами.
- Короткие интерфейсные переходы: 150–300 мс. Крупные переходы экранов: 300–500 мс. Больше 600 мс обычно уже мешает.
- Выход быстрее входа: появление плавное, исчезновение короткое.
- При `prefers-reduced-motion` заменяй движение на затухание или отключай.

## Появление и исчезновение

1. **Затухание (fade).** Прозрачность от 0 до 1. Универсально, 200 мс, ease-out.
2. **Подъём снизу (slide up).** Элемент поднимается на 12–24 пикселя и появляется. Для карточек и блоков, 300 мс.
3. **Масштаб (scale in).** От 0.92 до 1. Для модальных окон и всплывающих подсказок, 200 мс.
4. **Раскрытие по высоте (expand).** Блок увеличивается по высоте, остальное сдвигается. Для аккордеонов и меню.
5. **Проявление по маске.** Изображение открывается шторкой или кругом. Для героев страниц, 600 мс.
6. **Печать букв.** Текст появляется по символам. Для заголовков, не для длинных абзацев.
7. **Появление по строкам.** Строки текста появляются одна за другой с задержкой 60–80 мс.
8. **Волновое появление (stagger).** Список элементов появляется по очереди с задержкой 40–60 мс между ними.

## Переходы между экранами

9. **Сдвиг вбок (slide).** Экран уходит влево, новый приходит справа. Для навигации по шагам.
10. **Наложение (cross-fade).** Старый экран тает, новый проявляется. Для смены контента на той же странице.
11. **Увеличение (zoom into).** Карточка растёт до полного экрана. Для перехода от списка к подробностям.
12. **Вытягивание из элемента (shared element).** Картинка из карточки перетекает в заголовок новой страницы.
13. **Складывание (fold).** Экран складывается, как бумага. Для шагов мастера.
14. **Перелистывание страницы (page turn).** Для журналов, книг, истории.
15. **Круговая шторка (circle reveal).** Новый экран открывается кругом из точки касания.

## Состояния и обратная связь

16. **Нажатие (press).** Кнопка уменьшается до 0.96 при касании и возвращается. 100 мс.
17. **Пульсация.** Элемент слегка увеличивается и уменьшается. Для уведомлений и таймеров. Редко, иначе отвлекает.
18. **Встряска (shake).** Поле ввода дрожит при ошибке. 300 мс, три колебания по 4–6 пикселей.
19. **Галочка с рисованием (check draw).** Линия галочки дорисовывается. Для подтверждения, 400 мс.
20. **Заполнение (fill).** Кнопка или полоса заполняется цветом по прогрессу.
21. **Счётчик (count up).** Число растёт от нуля до значения. Для цифр в статистике, 800–1200 мс.
22. **Переключатель (toggle).** Ползунок скользит, цвет меняется. 200 мс.
23. **Загрузка скелетоном (skeleton shimmer).** Блоки-заглушки с бегущим бликом пока грузится контент.
24. **Прогресс-кольцо.** Круг заполняется по процентам. Для загрузки с известным прогрессом.

## Движение элементов

25. **Плавание (float).** Элемент медленно двигается вверх и вниз на 4–8 пикселей. Для декора и иллюстраций, 4–6 секунд цикл.
26. **Покачивание (sway).** Лёгкий наклон туда-сюда. Для листьев, ярлыков, украшений.
27. **Вращение.** Постоянное вращение иконок загрузки или декора. Не для текста.
28. **Инерция (spring).** Элемент пружинит, немного перелетает цель и возвращается. Для кнопок-переключателей и жестов.
29. **Перетаскивание с инерцией.** Элемент продолжает движение после отпускания и замедляется.
30. **Магнит (snap).** Элемент притягивается к сетке или ближайшей точке.
31. **Параллакс.** Слои движутся с разной скоростью при прокрутке. Для глубины.
32. **Привязка к прокрутке (scroll-linked).** Анимация идёт по мере прокрутки: прогресс, поворот, появление.

## Текст и типографика

33. **Бегущая строка (marquee).** Текст движется горизонтально по кругу. Для лент новостей, брендовых полос.
34. **Смена слов (word swap).** Одно слово сменяется другим по вертикали. Для заголовков с вариантами.
35. **Масштаб буквы по весу.** Вес шрифта меняется при наведении или прокрутке (variable font).
36. **Мигающий курсор.** Вертикальная черта мигает в конце текста. Для терминальных стилей.

## Фон и свет

37. **Градиент, который дышит.** Цвета фона плавно смещаются. Медленно, 10–20 секунд. Осторожно: легко превращается в шум.
38. **Смещение бликов.** Свет скользит по поверхности карточки при наведении мыши.
39. **Мерцание (flicker).** Короткие перепады яркости для эффекта старого экрана или свечи. Не чаще нескольких раз в секунду.
40. **Шум и зерно.** Фактура смещается, создавая ощущение плёнки. Очень лёгкое движение.

## Что не делать

- Одновременно движутся больше трёх крупных элементов: глаз не знает, куда смотреть.
- Бесконечное движение в зоне чтения текста.
- Одинаковые задержки у всех элементов: получается механическая очередь, а не живой ритм.
- Длинные анимации на каждом переходе: интерфейс начинает тормозить на ощущении.
- Движение без отключения для пользователей, чувствительных к укачиванию.

## Кривые движения (easing)

- **ease-out** для появления: быстро начинает, мягко останавливается.
- **ease-in** для исчезновения: медленно начинает, быстро уходит.
- **ease-in-out** для переходов между состояниями.
- **spring** для жестов и кнопок: с лёгким перелётом.
- **linear** только для бесконечных циклов (вращение, бегущая строка).
